Setting up the osg-nrao provisioner
===================================

NRAO_2022_Bhatnagar GPU jobs, mostly from PATh (ap1.facility.path-cc.io).

The files in this directory match what's deployed. Run these from this directory.

0) Service accounts, roles and node access (once per namespace): see ../rbac/INSTALL.txt

   kubectl apply -n osg-nrao -f ../rbac/prp-htcondor-provisioner-account.yaml
   kubectl apply -n osg-nrao -f ../rbac/prp-htcondor-wn-account.yaml

1) Worker token secret (shared by the provisioner and the worker pods; not in this repo):

   kubectl create secret generic prp-htcondor-wn-secret -n osg-nrao --from-file=prp-wn.token=<token file>

2) Provisioner config:

   kubectl create configmap nrao-provisioner-config -n osg-nrao --from-file=osg_provisioner.conf=osg_provisioner.conf

   The config is mounted with subPath, so after changing it restart the provisioner
   (kubectl rollout restart deploy/<name> -n osg-nrao).

3) Volumes: CVMFS (mounted into every worker pod) and the provisioner's log PVC:

   kubectl create -f cvmfs-nrao.yaml
   kubectl create -f pvc-provisioner-logs.yaml

4) The provisioner:

   kubectl create -f provisioner-pod.yaml
